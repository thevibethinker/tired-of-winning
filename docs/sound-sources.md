# Sound clip sources

All clips are short excerpts of Donald Trump's own recorded voice, used on a non-commercial watch-party page for political parody and commentary. Each was downloaded from a public Myinstants page on November 3, 2026, trimmed with ffmpeg, faded (10 ms in, 90 ms out), loudness-normalized (`loudnorm=I=-16:TP=-1.5`), and encoded as 96 kbps mono MP3. A local faster-whisper (base.en) transcription confirmed each clip's words; no cloud or paid transcription was used. Fair use is likely for this purpose but not guaranteed; remove a clip if a rights holder objects.
